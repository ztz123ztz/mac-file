# mac-spec usage
SPEC citations `[REF: x]` resolve against: measurement keys, `iso-hole-N`,
`dxf-view-<solid>-<view>`, BOM rows, `#o` selectors, and fixed keywords
(`overall`, `BOM-count`, `QA-report`, ...). Anything else lands in OPEN ITEMS.
Freeze triad: PART.md version == BOM footer == SPEC header, else BLOCKED.
